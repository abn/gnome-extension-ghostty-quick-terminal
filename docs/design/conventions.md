# Conventions

## Terminology

- Quick terminal: the Ghostty window managed by the extension.
- Toggle: the keybinding that shows or hides the quick terminal.
- Shell: GNOME Shell, the compositor and desktop the extension runs in.

## Writing

- Pages carry frontmatter with `type`, `title`, `description` and `status`.
- Links are relative. No absolute paths, no `file` URIs.
- Prose is plain. No em-dashes, no marketing language.
- When code and a page disagree, the code is right. Fix the page and record
  it in the log.
